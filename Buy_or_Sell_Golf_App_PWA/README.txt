# Buy or Sell Golf App

This is a phone-friendly web app / PWA prototype.

## How to use on iPhone
1. Upload this folder to any simple web host, or open the files locally on a computer.
2. Visit `index.html` in Safari.
3. Tap Share.
4. Tap "Add to Home Screen."

## What it includes
- Player setup
- 18-hole score entry
- Dynamic handicap standings
- Market ownership tracker
- Stock price ladder
- Bankroll tracker
- Rules and quick-start guide
- Offline-friendly service worker

## Notes
This is a prototype. For a true App Store / TestFlight app, this can be rebuilt in React Native, Swift, or Flutter.
